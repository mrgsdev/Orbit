# Orbit

Личная база контактов для десктопа на Flutter: не просто телефонная книга,
а память о людях — где познакомились, чем занимаются, что их интересует.

## Возможности

- Имя, телефон, Telegram, email, должность, компания, где и когда
  познакомились, день рождения, сфера интересов, заметки и фото.
- Свои разделы и поля: текст, число, телефон, email, ссылка, дата, список
  вариантов, да/нет. Названия, иконки и порядок настраиваются, любое поле
  можно вывести колонкой в таблицу.
- Таблица и карточки, поиск по всем полям (⌘K), фильтры по интересам,
  сортировка, статистика, массовые действия, экспорт в CSV.
- Светлая и тёмная тема по системе.

## Запуск

```bash
flutter pub get
flutter run -d macos
```

Поддерживаются macOS, Windows и Linux.

## Где хранятся данные

В папке Application Support приложения (на macOS — внутри песочницы
`~/Library/Containers/dev.mrgs.orbit/`):

- `contacts.json` — контакты;
- `schema.json` — пользовательские разделы и поля;
- `photos/` — копии фотографий контактов.
